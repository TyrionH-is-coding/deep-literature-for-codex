## 原生格式、接口与白名单

以下引用均对应源码审计 JSON 中的包名、`lib/index.js` 和行号，不是上游最新文档。

- `dsh-session`：会话 header version=0；事件使用 seq/time/type/data、可选 surfaceOp/sourceEventSeqs/ignorable；KNOWN_SESSION_EVENT_TYPES 是固定版本目录。父子关系由 parentSession/origin/delegationDepth 表示，seedLength 影响 Inbox 的重建起点。不能只按文件名猜关系。
- `dsh-session-persistence-jsonl` 24–70、103–158、767–898：`<sessions>/<projectKey(cwd)>/<encoded sessionId>/session.jsonl.zstd`，也支持 plaintext `.jsonl`；header 首行 type=session。压缩支持多帧及 chunk-run 紧凑编码。`locate` 生成目录；读取会验证 header id/cwd 与实际位置一致；不能只改目录名。
- 后端 `readRaw` 提供原生无损日志导出，`readFrom(id,0)` 给解码事件；`inspect` 不发布 live Session、不提交恢复；`prepare/load` 可提交恢复修复；`materialize(meta,events)` 是实际可调用的后端方法，本次仅作为固定版本离线探针使用，不是已承诺的稳定产品导入 API。
- `dsh-session` 605–726：未完成 turn 的逻辑读回会追加工具错误结果及 step/turn 边界。已开始无结果为 `TOOL_OUTCOME_UNKNOWN`，尚未开始为 `TOOL_NOT_STARTED`。本次覆盖前者。原始前缀不被重写，但 warm resume 会把修复追加到磁盘；因此“历史相同”必须明确为原始事件保留+有记录的原生追加修复，不能要求所有重启阶段字节恒等。
- `dsh-agent` 10–42、137–162：队列没有独立待发文件，由历史 `agent/inbox/spliced` 投影 next-turn/next-step；工具调用/结果也在同一日志。`dsh-agent-loop` 350–398、1230–1287 的恢复创建 idle agent；send 的 wakeup 才唤醒驱动。本次原生查询与挂载验证支持此结论，但不是任意插件组合的全局禁执行保证。
- `dsh-workspace`：storage-domain `workspace` version=2，JSON 后端文件 `home/storages/workspace.json`；`global` 含 initialized/workspaceIds/archivedSessionIds/pendingMutation，`tables.workspaces[id]` 含 path/title/sessionIds/createdAt/updatedAt。启动会按 realpath 建立 header 索引。空 registry 可以从历史 bootstrap，但会丢失自定义展示状态，因此本次显式迁移最小 registry，拒绝 pendingMutation。
- `dsh-session-projection-cache`：`storages/session_projcache.json` 是可重建投影，不作为权威历史导出；session-query-sqlite 为衍生搜索索引，Web 默认 `:memory:`、openAt=never。本次未复制缓存或搜索库。
- `dsh-host-apiproxy` 有真实导出端点和历史/查询/创建/发送等 RPC；审计提取的 session RPC 表没有 import。导出也可包含被引用图片 media 条目，但本次没有图片附件，不能声称附件恢复已验证。

探针采用的文件/字段合同：

| 允许 | 映射/约束 |
|---|---|
| 两个 session 日志的解码 header + 全部原事件 | header 仅 version/id/createdAt/cwd/parentSession/seedLength/origin/delegationDepth/agentPreset；version=0；保留 ID，拒绝重复/悬空/环；cwd 映射并通过原生 locate/materialize 重建位置 |
| workspace.json 的 version=2 单 workspace | 新 UUID/path，保留注册顺序、归档集合、名称、时间与 sessionIds；pendingMutation 必须不存在；本夹具不处理多 workspace 合并 |
| 已核实的原生导出 JSONL | 保留原件作证据；本次适配从后端 readFrom 的解码对象生成，没有把浏览器 ZIP 当作通用导入格式 |

排除其余 DSH_HOME 文件，特别是 `.credentials.yaml`、settings.yaml、profile/patch/env、日志、运行态、缓存、插件代码和安装路径。`dsh-credentials-local` 45–60、154–209 明确还可从继承环境及 `.env` fallback 取值；宿主仅继承系统路径/临时目录基础环境，HOME/USERPROFILE/DSH_HOME 均指向合成根，credentials 和外部模型适配器禁用。计数器适配器不发网络模型请求，唯一模型返回是本地 JS。

本白名单是探测合同，不是可直接上线的备份允许列表。自由文本、工具结果、附件可能含秘密；已知 canary 只能证明该值被拒绝。无法在保持任意历史语义的同时自动保证无未知秘密。未来需明确允许数据范围和用户处理方式，不能静默删除敏感事件后宣称完整恢复。
