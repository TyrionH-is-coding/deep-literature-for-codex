```powershell

$node006 = 'C:/tmp/v006/source/runtime/node/22.22.2/node.exe'
# 已执行，产物 backup-r4 存在；勿重跑并覆盖。
```

`validate` 自身执行两次实际启动/停止并逐条核对历史前缀、HTTP Reader 与 PDF 摘要。`continue` 明确提供 manifest、transaction、task、revision、幂等键及合成翻译/复核输入；先确认→等真实 worker 第二 gate→stop→旧请求不清 stop→新代确认→等原 parent 和唯一 child 完成→重复/模拟客户端未收到响应的同请求重试/旧请求核对。此重试实际为再次调用同一个 `continueRecovery` 请求；全部持久回执保留，未执行回执删除或网络丢响应故障注入。旧原始记录的 `lost external receipt retry` 标签仅表示该客户端重试场景。完整确认输入和返回对象在 `C:/tmp/v006/evidence/continue-恢复 工作台 r4.json`，脚本固定合成范围，不能当通用用户自动确认入口。

复演完整恢复可指定另一个尚不存在的新根；需要约数分钟安装。使用现有不可变备份，源及成功实例保持不变：

```powershell
$reviewRoot006 = 'C:/tmp/v006/复核 新根' # 必须不存在；再次演练换新名字
& $node006 scripts/acceptance-v02-006-roundtrip.mjs restore $reviewRoot006 r4

& $node006 scripts/acceptance-v02-006-gate-probe.mjs $reviewRoot006
& $node006 scripts/acceptance-v02-006-continue.mjs $reviewRoot006
& $node006 scripts/acceptance-v02-006-roundtrip.mjs validate $reviewRoot006 r4
```

只查看已完成中文根的历史、库和两篇 Reader，可通过可信 CLI 启动受门禁约束的查看实例，使用返回的 URL；看完停止。普通 `start` 和 maintenance 仍拒绝，没有全局解除门禁按钮：

```powershell
$root006 = 'C:/tmp/v006/恢复 工作台 r4'
$install006 = Get-Content -LiteralPath "$root006/installation.json" -Raw | ConvertFrom-Json
$cli006 = Join-Path $install006.app 'src/cli.mjs'
& $install006.node $cli006 instance-start-validation $root006 '8ee2a04f-ed2f-4977-9502-0e55666f72ec'
# 打开返回 URL；Reader 路径：/sr/reader/title_d8b339a0356f 和 /sr/reader/title_4405f12d0898
& $install006.node $cli006 stop $root006
```

直接 CLI 等价入口为 `instance-backup <source> <new-package-dir>`、`instance-restore <new-root> <options.json>`，options 包含 archive、packageRoot、runtimeCache（上述路径见 roundtrip 脚本）；`instance-validate <root> <transactionId>`、`instance-continue <root> <confirmation.json>`、`instance-stop <root> <stop.json>`。失败备份源专用 `instance-abort-backup <source> <transactionId>` 会重新冻结核验并写审计；不能用于失败恢复目标，也不会自动启动源。
